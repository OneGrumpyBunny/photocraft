Dalivinci portable mode

While this file sits next to photocraft.exe, Dalivinci keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the DalivinciData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Dalivinci with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Dalivinci for settings
and %LOCALAPPDATA%\Dalivinci\Recovery for crash-recovery autosaves. If DalivinciData can't be
written (for example on a read-only drive), Dalivinci says so and uses those folders instead.
